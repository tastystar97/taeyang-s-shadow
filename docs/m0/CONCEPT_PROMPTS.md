# 0단계 시안 생성 프롬프트

내장 image_gen을 사용했어. 참조 파일 편집은 ACL 오류로 실패해서 03·05·06·07은 같은 화면 설명에 교정 조건을 더한 새 시안으로 생성했어. CLI/API 키 경로는 사용하지 않았어.

## 공통 기준

용도: ui-mockup. 태양시 UGN 지부 인트라넷의 0단계 설계용 고해상도 화면 시안. 전체 데스크톱 앱 화면 한 장, 정면 1536x1024 비율, 브라우저/기기 테두리 없이. 실제 구현은 기존 HTML/JS/CSS이며 글자와 조작은 코드로 구현할 예정. 밝은 마케팅 페이지가 아니라 차분하고 읽기 쉬운 남색 업무 단말. 기존 지부장 화면에서 이어받을 색: 배경 #061018, 사이드바 #091923, 패널 #0c202b, 가는 구분선 #22414b, 본문 #d8e6e8, 보조 #7f9ba2, 강조 #8dd2df, 주버튼 #5aa6bc, 반려/삭제만 #d35f62. 한글은 맑은 고딕 계열 매우 선명하게, 본문 15px 이상, 제목 30px, 코드만 Consolas. 상단 높이72, 왼쪽 메뉴폭220, 본문여백36, 얇은 직선과 작은 6px 곡률, 광택/네온/스캔라인/큰 둥근 카드/사진 배경/무의미한 통계 금지. 상단 왼쪽 육각 UGN 심벌 옆 'TAEYANG CITY BRANCH'. 한글 메뉴는 관제 기준 '관제 개요', '사건철', '인사기록', '아카이브', '증거물', '전자결재', '운영 관리'. 상단 우측 '플레이어 미리보기'. 모든 메뉴와 실제 버튼은 선명하고 읽을 수 있게. 자료 공개는 반드시 개별 행/개별 자료에만 '공개' 또는 '공개 설정' 버튼. 전체선택 체크박스, 일괄공개, 전체공개, 자동공개, 다음장면공개 절대 금지. 의미 있는 실제 작업 공간으로 디자인하고 장식성 설명/추가 기능을 발명하지 마.

'문서' 부분에 허용된 자료 한 행만 '보호대상 안정화 및 인계 규정', 보조 'HQ-PD/P-07 · 본부 규정', '문서 열기' 버튼. 다른 비공개 자료의 제목, 수량, 빈 자리, 자물쇠 슬롯, 비공개 설명을 절대 표시하지 마. 공개설정/자료연결/메모/편집/보고서작성 버튼 없음. 표 한 개와 여백의 명확한 설계. 현장요원 실제 화면과 동일하게 보이는 자료만 보여주되 상단 미리보기 띠가 읽기 전용 상태를 표시해.
