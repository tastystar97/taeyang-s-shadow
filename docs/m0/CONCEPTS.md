# 0단계 화면 시안 모음

생성 방식: 내장 image_gen · 데스크톱 시안 7종 · 1536×1024
상태: 검토용 시안, 기능이 구현된 화면이나 최종 승인된 디자인은 아니야.

기존 지부장 화면의 남색·청록색, 사이드바와 흰 공문을 이어받아 정리했어. 이미지 속 날짜·보고 본문·인사 평가·공개 상태·파일명은 배치 예시야. 실제 시나리오와 저장 기록은 원본을 유지해.

## 화면 목록

| 화면 | 핵심 흐름 |
| --- | --- |
| 01 관제 아카이브 | 검색 → 원문 확인 → 자료 한 건 공개 설정 |
| 02 인사기록 편집 | 인사정보·첨부 수정 → 변경 저장 |
| 03 문서 등록 | 파일 선택 → 미리보기 → 비공개 저장 |
| 04 관제 사건철 | 자료 연결 → 각 자료의 공개 대상 확인 → 한 건씩 공개 |
| 05 지부장 결재 | 현장 보고 제출본 확인 → 승인·반려 |
| 06 현장 보고 작성 | 공용함 작성 → 임시저장 → 지부장에게 제출 |
| 07 플레이어 미리보기 | 대상 역할 선택 → 허용 자료 열람 → 관제 복귀 |

## 검토 결과와 최종 설계 때 맞출 항목

| 확인점 | 결과 |
| --- | --- |
| 공개 조작 | 관제의 자료별 버튼으로만 구성했어. 전체 선택·일괄 공개는 없어. |
| 미리보기 권한 | 초기 시안의 잘못된 공개 설정 열을 제거한 새 시안을 선택했어. 원문 열기와 시점 전환·복귀만 보여줘. |
| 업로드·공개 분리 | 문서 등록의 주버튼은 비공개 저장이야. 저장 직후 일반 공개를 하지 않아. |
| 결재 역할 | 지부장 화면에 현장 보고 승인·반려를, 현장요원 화면에 작성·제출을 배치했어. GM 열람 화면에서는 현장 보고 결재 버튼을 숨기는 설계야. |
| 자료 참조 | 현장 보고서의 관련 자료 버튼은 자료 선택으로 표시해. 새 파일 업로드로 오해할 찾기 버튼을 바꿨어. |
| 색과 문서 | 남색 화면과 흰 공문을 유지했어. 최종 CSS 값은 M0_DESIGN.md의 토큰으로 통일할 예정이야. |
| 브랜드 | 초기 시안의 잘못된 영문 조직명은 새 시안에서 제거했어. 실제 구현의 조직명·로고는 기존 원본을 사용해. |
| 간격·아이콘 | 시안마다 사이드바 폭·로고 크기·아이콘이 조금 달라. 최종 디자인 확정 때 한 컴포넌트 규칙으로 맞춰야 해. |
| 상세 필드 | 인사 편집 시안은 대표 필드를 보여줘. 등록일·배치·특기사항 등 전체 기존 필드는 설계서대로 유지하고 최종 폼에 포함해. |
| 모바일 | 메뉴 접기·단일 열·버튼 겹침 방지 규칙을 설계서에 정의했어. 모바일 세부 화면과 실제 반응형 동작은 후속 구현에서 검증해야 해. |

브라우저 확인은 기존 로컬 화면에만 했어. 앱 브라우저가 ACL 샌드박스 오류로 실행되지 않아 번들 Playwright와 설치된 Edge의 headless 모드로 1280×900 참고 화면을 확인했어. API를 연결하지 않은 정적 미리보기였고 새 기능을 검증한 것은 아니야.

view_image의 파일 읽기도 같은 오류로 실패해서 기존 화면은 이미지 데이터로, 생성 시안은 내장 도구 결과로 직접 확인했어. 새 앱과 시안의 픽셀 일치·모바일·기능 검증은 아직 하지 않았어. 이 문서를 최종 구현 검증 보고서로 취급하면 안 돼.

생성 프롬프트와 재생성 수정 사항은 CONCEPT_PROMPTS.md에 보관해.
